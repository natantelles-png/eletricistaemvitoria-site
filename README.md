# eletricistaemvitoria.com.br

Site estático (HTML, CSS) da Elétrica Conexão Vix, eletricista 24h em Vitória-ES.

- Sem JavaScript e sem build: publicar a raiz deste repositório (GitHub Pages: branch `main`, pasta `/ (root)`).
- Domínio: eletricistaemvitoria.com.br. Ao ativar o Pages, definir o domínio personalizado (o GitHub cria o arquivo `CNAME`) e ativar "Enforce HTTPS".
- O site é gerado a partir de um script externo; edições manuais podem ser sobrescritas na próxima geração.
